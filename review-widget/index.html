Review Widget

Multi-Platform Review Aggregator for Google, Airbnb, TripAdvisor, Yelp & Facebook

Features

Multi-Platform Support

Aggregate reviews from Google, Airbnb, TripAdvisor, Yelp, and Facebook in one place.

Multiple Layouts

Choose from Grid, Carousel, Masonry, or List layouts to match your website design.

Fully Customizable

Customize colors, fonts, spacing, and more with CSS variables or configuration options.

AI Summary

Automatically generate intelligent summaries of all your reviews for quick insights.

Smart Filtering

Filter reviews by platform, rating, or show only 5-star reviews to highlight the best feedback.

Image Support

Display review images with a built-in lightbox for full-size viewing.

Quick Start

1. Include the files

<link rel="stylesheet" href="review-widget.css">
<script src="review-widget.js"></script>

2. Create a container

<div id="review-widget-container"></div>

3. Initialize the widget

const reviews = [
  {
    name: "John Smith",
    avatar: "https://example.com/avatar.jpg", // optional
    rating: 5,
    text: "Amazing experience! Would definitely recommend.",
    date: "2025-01-15",
    platform: "google", // google, airbnb, tripadvisor, yelp, facebook
    verified: true,
    images: ["https://example.com/photo1.jpg"] // optional
  },
  // ... more reviews
];

const widget = new ReviewWidget('#review-widget-container', reviews, {
  layout: 'grid',           // 'grid', 'carousel', 'masonry', 'list'
  theme: 'light',           // 'light', 'dark'
  snippetLength: 150,       // characters before truncation
  showAiSummary: true,      // show AI-generated summary
  showImages: true,         // show review images
  minRating: 1,             // minimum stars (set to 5 for 5-star only)
  platforms: ['google', 'airbnb', 'tripadvisor', 'yelp', 'facebook']
});

Configuration Options

Option Type Default Description
layout string 'grid' Layout style: 'grid', 'carousel', 'masonry', 'list'
theme string 'light' Color theme: 'light' or 'dark'
reviewsPerPage number 6 Number of reviews to show per page
snippetLength number 150 Maximum characters before truncation
showAiSummary boolean true Show AI-generated review summary
showStats boolean true Show rating statistics
showFilters boolean true Show platform and rating filters
showImages boolean true Show review images
showAvatars boolean true Show reviewer avatars
showDates boolean true Show review dates
showPlatformBadge boolean true Show platform icon/badge
minRating number 1 Minimum rating to display (1-5). Set to 5 for 5-star only.
platforms array ['google', ...] Platforms to include in display
autoplay boolean false Auto-rotate carousel
autoplaySpeed number 5000 Carousel autoplay interval (ms)
primaryColor string null Custom primary color (e.g., '#ff5a5f')
aiSummaryText string null Custom AI summary text (overrides auto-generated)

Styling with CSS Variables

/* Override default styles */
:root {
  --rw-primary-color: #ff5a5f;      /* Primary accent color */
  --rw-background: #ffffff;          /* Widget background */
  --rw-card-background: #ffffff;     /* Review card background */
  --rw-text-primary: #1e293b;        /* Primary text color */
  --rw-text-secondary: #64748b;      /* Secondary text color */
  --rw-border-color: #e2e8f0;        /* Border color */
  --rw-star-filled: #fbbf24;         /* Filled star color */
  --rw-star-empty: #e2e8f0;          /* Empty star color */
  --rw-radius-lg: 0.75rem;           /* Border radius */
  --rw-font-family: 'Your Font', sans-serif;
}

API Methods

// Update reviews dynamically
widget.setReviews(newReviews);

// Add a single review
widget.addReview({
  name: "New Reviewer",
  rating: 5,
  text: "Just added!",
  platform: "google",
  date: new Date().toISOString()
});

// Update configuration
widget.setConfig({
  layout: 'carousel',
  minRating: 4
});

// Get current config
const config = widget.getConfig();

// Get filtered reviews
const filtered = widget.getFilteredReviews();

// Destroy widget
widget.destroy();

Event Callbacks

  onReviewClick: (review, index) => {
    console.log('Review clicked:', review);
  },
  onLoadMore: (page) => {
    console.log('Loading page:', page);
    // Fetch more reviews from API
  },
  onFilterChange: (filters) => {
    console.log('Filters changed:', filters);
  }
});
